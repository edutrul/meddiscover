# Contributing

Read [PLAN.md](PLAN.md) and [AGENTS.md](AGENTS.md). Phase 07 is approved.

Select an existing issue or create one with context, objective, scope, acceptance criteria, dependencies, exclusions and validation. Synchronize main, branch as `med-{issue}-{short-title}`, implement only approved scope, validate and document, then commit and push. Open a PR titled `MED-{issue}: Short descriptive title`; use `Closes #N` only when all acceptance criteria are met. Request owner review. Merge requires explicit approval and successful required checks. Verify issue closure after merge.

Milestones represent phases; labels classify work. Do not create future-phase implementation issues or GitHub Projects. All repository artifacts are English. Never publish secrets or private materials.
